# 🏹 Nhe'ẽ IA - Inteligência Artificial & Linguística Tupi

Uma aplicação web moderna, responsiva e culturalmente rica que serve como interface para um Chatbot de IA especializado na língua e cultura **Tupi Antigo (Tupinambá)**.

---

## 🎨 Características Visuais e Culturais
- **Paleta de Cores Inspirada na Natureza e Tradição Indígena:**
  - 🌿 **Verde Floresta / Esmeralda:** Fundo, cartões e elementos naturais.
  - 🔴 **Vermelho Urucum Vívido:** Botões de envio, chamadas de ação e acentos.
  - ☀️ **Amarelo Ocre / Dourado:** Badges, detalhes, realces e ícones solares.
  - 🏺 **Terracota Suave:** Acentos secundários e informativos.
- **Modo Claro e Modo Escuro (Dark/Light):** Alternância instantânea com preservação de contraste e elegância.
- **Tipografia:** Google Fonts (*Cinzel* para títulos ancestrais e *Plus Jakarta Sans* para legibilidade de leitura).

---

## 🚀 Funcionalidades da Aplicação
1. **Interface de Chat Interativa:**
   - Balões diferenciados com avatares estilizados (Usuário vs Nhe'ẽ IA).
   - Botão para **Copiar Resposta** com aviso toast.
   - Botão para **Ouvir Pronúncia** (usando síntese de voz / Web Speech API).
   - Suporte a formatação rica em Markdown (tabelas, listas, negrito, blocos de citação).
   - Indicador visual animado de digitação (*"Nhe'ẽ IA está pensando..."*).
2. **Chips / Sugestões Rápidas de Perguntas:**
   - *"Como se diz 'bom dia' em Tupi?"*
   - *"Qual a origem e o significado da palavra 'Ibirapuera'?"*
   - *"Me conte uma lenda ou história da mitologia Tupi."*
   - *"Como traduzir a frase 'A floresta é grande' para o Tupi?"*
3. **Dicionário & Glossário Tupi (Modal Dinâmico):**
   - Mais de 18 termos essenciais catalogados por categorias (*Conceito Sagrado, Natureza, Fauna, Etimologia, etc.*).
   - Barra de pesquisa em tempo real.
   - Clique em qualquer termo para perguntar diretamente no chat.
4. **Painel "Sobre o Projeto":**
   - Informações sobre o significado de *Nhe'ẽ* (falar, espírito, alma).
   - A herança de mais de 10.000 vocábulos Tupi no Português falado no Brasil.
5. **Autônomo (Single-File):**
   - HTML5 puro, Tailwind CSS via CDN, Lucide Icons e Marked.js.
   - Pronto para rodar no navegador ou publicar via GitHub Pages!

---

## 💻 Como Abrir e Testar Localmente
Basta dar um duplo clique no arquivo [`index.html`](index.html) para abrir diretamente em qualquer navegador moderno (Chrome, Edge, Firefox, etc.).
